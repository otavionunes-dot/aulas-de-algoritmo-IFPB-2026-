# Estruturas de Repetição em JavaScript (Loops) 🔄

Repositório criado para registrar os estudos, anotações e exercícios práticos sobre estruturas de repetição (loops) em JavaScript, desenvolvidos na disciplina de Programação Web do **Instituto Federal da Paraíba (IFPB)**.

## 📝 Descrição do Projeto

Este projeto centraliza o aprendizado de controle de fluxo repetitivo em JavaScript. O objetivo principal é compreender como executar um bloco de código múltiplas vezes de forma eficiente, aplicando os conceitos em algoritmos de ordenação, varredura de arrays, manipulação de objetos e lógica de programação geral.

## 🚀 Conceitos Estudados

O repositório está dividido em exemplos práticos de cada tipo de loop:

* **`while`**: Executa um bloco de código enquanto uma condição específica for verdadeira (indicado quando não sabemos o número exato de repetições).
* **`do...while`**: Semelhante ao `while`, mas garante que o bloco de código seja executado **pelo menos uma vez** antes de testar a condição.
* **`for`**: Ideal para repetições onde sabemos previamente a quantidade exata de iterações (possui inicialização, condição e incremento na mesma linha).
* **`for...of`**: Criado para percorrer os valores de estruturas iteráveis, como elementos de um Array ou strings.
* **`for...in`**: Utilizado para iterar sobre as propriedades (chaves) de um objeto.

## 🛠️ Tecnologias Utilizadas

* **Node.js** (para execução dos scripts via terminal)
* **Visual Studio Code** (Editor de código)
